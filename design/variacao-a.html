Por que usar async/await

No seu projeto, a função de busca chama a API e espera a resposta. Sem async/await, o código continuaria antes dos dados chegarem — e você trabalharia com valores vazios.

A palavra await pausa a função até a Promise resolver, deixando o código assíncrono com cara de síncrono. 

async function buscar(id) {
  const res = await fetch(`/api/${id}`);
  return res.json();
}

Repare que quem chama buscar() também precisa usar await — o assincronismo "sobe" pela cadeia de chamadas.
