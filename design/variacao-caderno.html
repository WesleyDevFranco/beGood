Chamadas assíncronas no projeto

No seu projeto, a função de busca chama a API e espera a resposta. Sem async/await, o código seguiria antes dos dados chegarem — e você trabalharia com valores vazios. 

async function buscar(id) {
  const res = await fetch(`/api/${id}`);
  return res.json();
}
✓ Exercício 1 — concluído

A palavra await pausa a função até a Promise resolver. Mas atenção: quem chama uma função async também precisa lidar com o retorno — e casos de borda, como uma lista vazia, precisam de tratamento explícito.
